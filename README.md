# Hotmess Ines — UGC Creator Portfolio

A hand-coded, single-page vertical-scroll portfolio site for Ines Quezada
(@Hotmess_Ines), a bilingual UGC creator and makeup artist.

Rebuilt from the original Canva Site as a plain static HTML/CSS site so it
can be self-hosted (GitHub Pages) without Canva branding or the horizontal
slide-scroll layout.

## Structure

- `index.html` — all page markup/content
- `styles.css` — theme (black / white / yellow), layout, responsive rules
- `images/` — portfolio photos

## Local preview

Just open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

## Deploy

Static site — works as-is on GitHub Pages, Netlify, Vercel, or any static host.
